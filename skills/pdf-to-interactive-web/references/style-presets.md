# 风格预设

用户说了风格就照做；没说就按内容挑一个。下面每个预设只给方向：配色、字体、质感、适合画什么、要避开什么。具体怎么画由你决定，技法不用写得太细，写细了反而画得拘谨。

## 字体：只用系统自带字体

不要引用 Google Fonts 这类外部字体：中国大陆的网络经常加载不出来，页面会退回默认字体，风格全没了。用系统字体栈：

- 宋体 / 衬线：`"Songti SC", "STSong", "Noto Serif CJK SC", "Source Han Serif SC", SimSun, serif`
- 楷体：`"Kaiti SC", "STKaiti", KaiTi, "BiauKai", serif`
- 黑体 / 无衬线：`-apple-system, "PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif`
- 等宽：`"SF Mono", Menlo, Consolas, "Courier New", monospace`

需要特殊字形（像素字、手写字）时，用 SVG 或 Canvas 把标题画出来，正文仍用系统字体。

## 预设

### 中国古画（适合：古典小说、历史、诗词）
- 配色：绢黄或宣纸米白做底，墨色线条，淡彩点缀（赭石、花青、朱砂、石绿），大面积留白。
- 字体：楷体做标题，宋体做正文；竖排题字配朱红印章。
- 质感：纸张纤维和做旧斑驳要轻，不要盖过画面。
- 主视觉：界画式的建筑、工笔人物、手卷或册页构图；把原文里的匾额、对联、器物、服饰画进去。
- 避开：卡通脸、几何形拼人物、满屏水渍。

### 18 世纪铜版地图与手稿（适合：数学、科学史、地理）
- 配色：羊皮纸色或深棕底，深褐墨线，一种强调色（朱红或铜绿）。
- 字体：衬线体，标题可以加大写拉丁字母做装饰；图注用斜体。
- 质感：雕版式的排线阴影、罗盘玫瑰、比例尺、图版编号（PL. I、TAB. II）。
- 主视觉：古地图、木制模型、手稿页上的几何图。
- 避开：现代扁平图标。

### 工程蓝图（适合：技术论文、系统架构、机械原理）
- 配色：深蓝底加白线，或白底加蓝线；一种警示色（琥珀黄）标重点。
- 字体：等宽体做标注，无衬线体做正文。
- 质感：网格底纹、尺寸线、图框和标题栏（DWG、SHEET 01/07）。
- 主视觉：等轴测剖面、分层总装图、数据流示意。
- 避开：把论文原图原样重画一遍就算完，要画出原图没有的那层直观。

### 1950 年代美式复古海报（适合：商业、消费品、财报）
- 配色：奶油底，番茄红、薄荷绿、芥末黄，深海军蓝。
- 字体：粗衬线体或粗无衬线体做大标题（可用 SVG 描边加阴影），正文用无衬线体。
- 质感：网点、放射光芒、徽章、横幅缎带、轻微错版。
- 主视觉：工厂流水线、送货卡车、地球仪、柜台；用插画讲清钱和货怎么流动。
- 避开：任何真实公司的商标、标志性瓶型和配色组合；不要让页面看起来像官方广告。

### 16-bit 像素游戏（适合：游戏规则、流程、任务清单）
- 配色：深夜蓝底，有限调色板（16 色左右），高饱和的强调色。
- 字体：标题用 Canvas 画像素字，或等宽粗体加大字距；正文用系统无衬线体保证可读。
- 质感：像素边框、对话框、血条、经验条、关卡编号。
- 主视觉：Canvas 画的像素场景（`image-rendering: pixelated`），比如地牢、城堡、战斗瞬间；每关一幅。
- 避开：只用像素字体、没有像素画；把整页做成密不透风的仪表盘。

### 水墨淡彩（适合：散文、诗、传统文化）
- 配色：大片留白，墨分五色，一两处淡彩。
- 字体：宋体或楷体，行距放宽。
- 主视觉：月、舟、山、门这类意象，构图要空。
- 避开：把水墨做成灰色的扁平插画。

### 杂志特稿（适合：商业分析、人物、社会议题）
- 配色：白底黑字，一种品牌强调色。
- 字体：大号衬线标题，无衬线正文，引语放大。
- 主视觉：大幅数据图、引语墙、时间轴。
- 避开：卡片堆叠的仪表盘感。

### 手绘课堂笔记（适合：教材、考试复习、入门讲解）
- 配色：方格纸或横线纸底，蓝黑笔迹，荧光笔高亮。
- 字体：标题用 SVG 手写风描边，正文用系统字体。
- 质感：便利贴、箭头、圈画、批注。
- 主视觉：手绘图解、推导过程。
- 避开：把手写字体用在大段正文上。

### 深色数据仪表盘（适合：论文复现、评测报告、数据管线验证、实验复盘）
- 配色：近黑深蓝底（`#080b14`–`#0f172a`），卡片比底色亮一档；文字用冷白到灰蓝三档；强调色只留两三个——冷青或翠绿为主，琥珀标「警告/待确认」，玫红标「失败/缺失」。想更炫就把大标题换成青紫渐变，其余不动。
- 字体：系统无衬线做标题正文；等宽体包办所有数字、指标、字段名和代码路径；hero 大标题可以极粗。
- 质感：极淡的科技网格（四周淡出）、顶栏 2px 滚动进度条、圆角药丸标签（编号/机构/日期）、卡片 1px 边框加大阴影、区块左侧 2px 强调色竖条、表头比正文稍亮、行悬停微亮。
- 主视觉：hero 大标题 + 一句话结论 + 超大等宽指标条（数字 40px 以上，下面一行小字注释）；左侧粘性目录配右侧正文；深色代码块和文件树；用绿点/红点做「已完成/未覆盖」的范围格。
- 避开：满屏霓虹发光和彩虹渐变；纯黑底配纯白字（要蓝调黑加冷白）；每个段落都套卡片，留不出呼吸。

### 夜间仪器（适合：数学、几何、位姿与坐标系、单概念深讲）
- 配色：近黑底，暖象牙白正文（不用纯白），只一种金色强调；量值用一套低饱和通道色（粉、绿、青、蓝），一个量认一个颜色。
- 字体：大标题用衬线（宋体栈），可让其中一个词换金色斜体；正文无衬线；坐标、公式、读数一律等宽；顶部导航用小号等宽大写字母加字距。
- 质感：几乎没有卡片阴影，用 1px 暗金细线分区；留白大，字号对比狠；圆角药丸按钮；网格和坐标轴本身就是装饰。
- 主视觉：两行巨型衬线标题（中英混排）、可拖动的 3D 坐标轴或几何示意、底部一排实时读数（每格一个色点加等宽数值）、窄测量栏正文。
- 避开：亮底、饱和霓虹、仪表盘式的信息密度；金色只做点睛，一多就俗。

### 浅色工程手册（适合：使用文档、SOP、流水线讲解、入门教程）
- 配色：冷白纸底（`#f7f8fa`–`#fbfbfd`），纯白卡片，浅灰细线；主强调是低饱和橄榄绿，另配藏青、赭橙、紫、玫红四种语义色，每种配 8% 左右的浅底。
- 字体：系统无衬线正文 15px、行高 1.7；等宽体做目录编号、字段名、标签和代码；标题中等字重，不用超粗。
- 质感：左侧固定目录（编号 + 二级缩进 + 当前项浅绿底）；细线分隔、几乎无阴影；卡片顶部 2px 语义色边 + 小图标 + 一句话小标题；表格紧凑左对齐、表头浅灰；可提供深色切换。
- 主视觉：`01 / 02` 编号章节、分层示图（层框 + 向下箭头 + 每层「损失什么」）、职责对照表、可切换 tab 的表格、实线必需/虚线可选的流程条。
- 避开：高饱和大色块、居中大 hero、装饰性插画；别把文档做成营销落地页。

### 暖纸现场手册（适合：标定、装配、现场操作、验收清单）
- 配色：暖白纸底（`#fbfaf7`），白卡片，暖灰细线；主色钢蓝；状态色直接语义化——绿=已完成、黄=部分、红=待定/阻塞、琥珀=警告；代码块用墨黑底配暖白字。
- 字体：无衬线正文 15.5px、行高 1.75；命令、文件名、参数全用等宽；标题偏紧凑粗体，带一点印刷感。
- 质感：像印出来的技术手册——细横线分隔、浅色表头、10px 小圆角、阴影极轻；目录带步骤编号和子步骤缩进；状态用色点或小图标直接写进正文标题和目录。
- 主视觉：状态总览表（编号 / 项目 / 状态 / 用途 / 产物）、步骤块（步骤与命令 → 产物 → 验收标准）、深色代码块、琥珀提示条、文末待办清单。
- 避开：渐变和发光；状态色过饱和；把所有内容都装进卡片。

## 自定义风格

用户给了列表之外的风格（比如「赛博朋克」「宫崎骏」「报纸头版」），先用一句话把它翻译成「配色 + 字体 + 质感 + 主视觉」四项，写在页面注释里，再动手画。涉及具体在世艺术家或品牌时，只取大致的气质，不模仿可识别的作品和标志。
