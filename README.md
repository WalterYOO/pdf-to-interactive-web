# pdf-to-interactive-web

把难啃的 PDF，变成一个能玩、能核对的单文件网页。

上传一份 PDF（或其中一节），你的 AI 编程助手会：判断这份内容该怎么读 → 先建一张「事实账本」→ 做出一个单文件 HTML：首屏 30 秒讲清重点、可以动手的场景、先猜再看、每个数字都能点开原句和页码 → 最后对照原文自检。

适合：论文、教材章节、财报和年报、规则书和手册、小说章节、讲义。

## 安装

```bash
npx skills add ai-azhou/pdf-to-interactive-web
```

- 加 `-g` 装到全局，所有项目都能用。
- 加 `-a claude-code`（或 `codex`、`cursor`、`gemini-cli` 等）只装给指定的 AI 助手。

## 用法

装好以后，直接对你的 AI 助手说，例如：

- 「把 `report.pdf` 的第 3 节做成一个能玩的网页，风格用工程蓝图。」
- 「这本规则书我完全看不进去，帮我把战斗那一章做成交互网页。」
- 「把这份年报做成一个 5 分钟看懂它怎么赚钱的页面，复古海报风。」

产出是一个 `index.html`，双击就能打开，离线可用，不依赖任何外部库或字体。

## 里面有什么

```
skills/pdf-to-interactive-web/
├── SKILL.md                      主流程：定范围 → 定读法 → 事实账本 → 结构 → 风格 → 页面 → 自检
├── references/
│   ├── reading-modes.md          5 种读法：叙事、概念、查读、数据、论证，各自的骨架和交互
│   ├── style-presets.md          12 种风格预设，以及只用系统字体的字体栈
│   ├── page-contract.md          页面规范：出处角标、回到原处、先猜再看、阅读进度
│   ├── fidelity-checklist.md     准确性自检：实测中出现过的 9 类转述错误
│   └── prompt-standalone.md      给不能装 Skill 的网页聊天用的独立提示词
└── scripts/
    └── audit_html.py             零依赖自检脚本：外部资源、可见字数、角标、必备功能
```

## 没有 Skill 也能用

在 Gemini、DeepSeek、ChatGPT 这类网页聊天里，把 `references/prompt-standalone.md` 里的提示词和 PDF 一起发过去就行。Skill 版多出来的是「事实账本」和「自检」两步，它们专门用来减少数字和规则上的错误。

## 背后的实验

这个 Skill 来自一次对照实验：
- **材料**：5 种公认难读的 PDF（古典小说章节、AI 技术论文、离散数学教材、上市公司年报、桌游规则书）。
- **过程**：提示词迭代 4 轮；2 个模型（Claude Opus 5.5 和 DeepSeek V4.1 Flash）；用另一个 AI 逐条对照原文核查了 4 轮，每轮抽查 60 处。

几个结论：

- 只给一句话，模型就能做出好看的网页，但不一定比原文好读：平均 23 屏，首屏没有结论。
- 写「省时间」没用，写「默认可见不超过 2500 字」才有用。
- 插画只画 2–4 幅主视觉，比每个场景都配图好得多；写美术方向就够了，技法写得越细，画得越拘谨。
- 错误几乎都出在「把原句压缩成一句大白话」这一步：单位换算错位、主客体颠倒、丢掉例外条件。规则书最容易错，4 轮核查共 25 处矛盾，规则书占 14 处。

## 装 Skill 和不装，差多少

用同一句需求、同一个模型（Claude Opus 5.5），对两份最容易出错的材料，各做一次「装 Skill」和「不装 Skill」，再让另一个 AI 对照原文，每页抽查 12 处：

| | 与原文矛盾 | 原文没有、也没标注 | 默认可见汉字 | 先猜再看 / 自测 |
|---|---|---|---|---|
| 规则书 · 装 Skill | 0 | 0 | 2,082 | 4 处 / 有 |
| 规则书 · 不装 | 0 | 0 | 6,483 | 0 / 有 |
| 年报 · 装 Skill | 0 | 0 | 1,244 | 3 处 / 有 |
| 年报 · 不装 | 1 | 2 | 2,335 | 0 / 无 |

- 装 Skill 的两页，24 处抽查全部有据可查；不装的年报页，把「向公司或授权供应商购买」写成了「只能向公司买」。
- 装 Skill 的规则书页，在自检步骤里自己找出并改掉了 5 处转述错误，其中一处主客体写反。
- 代价是时间：同一份年报，装 Skill 用了 39 分钟，不装用了 15 分钟。
- 每种情况只跑了一次，只能看方向。同一份材料两次生成的差异本来就不小。

## 局限

- 每份内容一次生成，结果有随机性。
- 自检只能挡住常见错误，不能替代读者自己核对。规则、合同、财报数字这类材料，请点开角标对一下原句。
- 请只处理你有权使用的文件，生成的页面也不要用来二次分发受版权保护的原文。
